# CodeShala AI Mentor

**Learn. Practice. Improve.** · CodeShalaByKMFL · Hackathon challenge PS04

CodeShala is a browser-only programming learning demo for Python, HTML, CSS, and JavaScript. It runs from the project files with no backend, package install, API key, or internet connection.

## Run it

1. Open the project folder.
2. Double-click the root `index.html` (or open `frontend/index.html` directly).
3. Use the sidebar to try the tutor, practice quiz, learning path, code clinic, and progress screens.

The app is plain HTML, CSS, and JavaScript. It uses relative asset paths and stores the learner profile and progress in browser LocalStorage.

## What works offline

- **Local tutor:** short, topic-aware explanations in English, Hindi, or Hinglish. Replies are curated/pattern-based, not generated by a live AI model.
- **Practice quiz:** local questions, instant scoring, explanations, and saved attempts.
- **Adaptive learning path:** uses the last three attempts per topic. Below 60% suggests review, 60–79% suggests more practice, and 80% or higher suggests a challenge.
- **Code clinic:** local static checks and suggestions. It never executes submitted code.
- **Progress dashboard:** topic scores, quiz history, completed lessons, and light/dark theme.
- **Optional browser features:** speech input/output when supported by the browser.

No sample scores are preloaded. A quiz attempt is stored only after the learner submits answers. Data remains in that browser and is not synced between devices.

## Demo flow

1. Open the dashboard and select a subject.
2. Ask the local tutor to explain a concept, such as Python loops.
3. Take a quiz and submit answers; the score is saved on this device.
4. Open the learning path to see topic recommendations based on the attempt.
5. Paste a snippet into Code Clinic and note that it is reviewed locally, never executed.

## Privacy and limitations

The standalone frontend makes no backend/API requests. Profile and progress stay in browser storage. Clearing site data removes them. Tutor replies and code checks are local demo logic—not live AI or a full compiler—so present them accurately during a hackathon demo.
